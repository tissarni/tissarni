# Titouan Issarni

Software engineer and DevOps Lead. I build tools to automate engineering work, with a current focus on coding agents and developer tooling.

I enjoy working across the full lifecycle of a solution: understanding the problem, making design decisions, and seeing it through deployment and operation.

## Current work

I’m building the workflows around coding agents: written briefs, separate review and implementation sessions, acceptance checks, and project context that persists outside the conversation.

I use this system daily for professional and personal projects. I define the requirements and validate the results, while implementation can proceed without my continuous attention.

Two open-source projects support this workflow:

| Project | Purpose |
| --- | --- |
| [handoff-kit](https://github.com/tissarni/handoff-kit) | Runs coding-agent sessions from written briefs, with review, execution, close and debrief stages. |
| [agent-brain](https://github.com/tissarni/agent-brain) | A Markdown-based workspace for project context, engineering decisions, reusable skills and implementation briefs. |

A particular focus is preserving why a decision changed, not just the resulting code. I use debrief and lesson-capture workflows to carry that reasoning into subsequent sessions.

## Engineering interests

- Agent execution, persistent context and verification.
- Software that remains understandable and maintainable when handed over.
